# 전 과정 통합 시나리오

사람이 콘솔을 쓰는 순서 그대로, 브라우저에서 한 번에 돌린다. 단위 시험이 아니다 —
콘솔(:5173)·API(:18090)·MongoDB·**실제 워커**가 떠 있어야 하고, 실행이 진짜로 끝나는 것을
화면에서 기다린다. 단계마다 캡처를 이 디렉터리에 남긴다.

```bash
uv run python -m foldfront.cli worker          # 워커 (정합성 점검 루프 포함)
cd web && npm run e2e                          # 시나리오 실행, 캡처 갱신
```

만드는 것은 전부 `E2E …` 이름과 시각 도장을 달고 있어 뒤에 찾아 지울 수 있다.

| 단계 | 하는 일 | 확인하는 것 | 캡처 |
|---|---|---|---|
| 1 | 프로젝트 개설 | 만든 프로젝트가 곧바로 선택되고 머리말이 그 이름을 말한다 | `01-project-created` |
| 2 | 회차 개설 | 「1차 설계」로 열리고 목표가 표에 보인다 | `02-round-opened` |
| 3 | 워크플로 저장 | 기본 템플릿을 불러 식별자를 바꿔 저장 · 점검 패널이 없다(빠진 것이 없으므로) | `03-workflow-saved` |
| 4 | 서열 붙여넣기 | 「기록할 회차」에 최신 회차가 기본 · 붙여넣자마자 「서열 2개 · 148, 148 잔기」 | `04-setup-input` |
| 5 | 점검·실행 | 「모든 모델을 해석했습니다」 · 시작 메시지에 프로젝트와 회차가 적힌다 | `05-run-started` |
| 6 | 실행 감시 | 워커가 끝낼 때까지 기다려 「성공」 · 상세를 열어 단계를 본다 | `06-run-succeeded` |
| 7 | 회차에 기록됨 | 프로젝트 화면의 1차 행에 성공 배지 | `07-round-has-run` |
| 8 | 결과 분석 | 실행이 비교 대상 목록에 있고 골라진다 | `08-analyze-lists-run` |
| 9 | 알림 | 종을 눌러 목록이 뜬다 | `09-notices-open` |
| 10 | 운영 | 「정합성 점검」이 점검 건수를 말한다 | `10-operations-reconcile` |
| 11 | 범위 전환 | 프로젝트를 「전체」로 바꾸면 대시보드가 전체 건수를 말한다 | `11-dashboard-whole` |

스펙은 `web/e2e/full-process.e2e.ts`. 처음 돌릴 때 잡힌 것 — 결과 분석 지표 표가 목록형 지표를
`[object Object]` 로 찍었다(고쳤다). 잔기 수는 148 이다(시나리오 작성자가 147 로 잘못 알고 있었다).

## 잘 안 되는 길 — 다섯 시나리오 더 (2026. 9. 17.)

전 과정은 잘 되는 길만 걷는다. 사람이 실제로 부딪히는 건 잘 안 되는 길이다.

| 파일 | 시나리오 | 확인하는 것 | 캡처 |
|---|---|---|---|
| `failure.e2e.ts` | 헤더만 있고 서열이 없는 입력 | 실행이 「실패」 · 상세에 원인 · 종에 「실패했습니다」 · 실패에는 되살리기가 없다 | `fail-*` |
| `repair.e2e.ts` | 실제 DB 에서 관찰됐던 상태(running · 단계 pending · 작업 없음 · 한 시간 방치)를 만들어 | 종에 「멈춘 듯합니다」 → **「되살리기」** → 알림이 사라지고 → 워커가 끝내 「성공」 | `repair-*` |
| `viewer.e2e.ts` | 로그인 계정을 조회자로 낮추고 | 저장·실행 단추 비활성 · 입력칸 비활성 · 운영·이용자 메뉴 없음 · 승인 대기·인증 경고 알림 없음 | `viewer-*` |
| `fork.e2e.ts` | 성공한 실행에서 「여기서 fork」 | 자식이 열리고 출처를 말함 · 「시작」 → 「단계부터 다시 시작했습니다」 → 성공 | `fork-*` |
| `studio.e2e.ts` | 노드 추가 → **마우스로 간선 끌어 잇기** → 점검이 「모델 미지정」을 짚음 → 고치기 → 저장 | 캔버스 상호작용은 단위 시험으로 못 잡는다 | `studio-*` |

여섯 시나리오 합쳐 약 40초. DB 를 직접 만져야 하는 부분(작업 지우기 · 역할 낮추기)은 하네스가 `mongosh` 로
하고 끝나면 되돌린다 — API 가 일부러 제공하지 않는 조작이라 그렇다.
